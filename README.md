# Odin Rock Paper Scissors ✊✋✌️

Simple Rock Paper Scissors game built for **The Odin Project Foundations**.

[Live Demo →](https://wujecdamian.github.io/odin-RockPaperScissors/)

<p align="center">
  <img src="./screenshot.png" alt="Game screenshot" width="360"/>
</p>

## Features

- Play against computer
- Click buttons to choose
- Keeps score
- Shows round result
- First to 5 wins

## Technologies

- HTML
- CSS
- Vanilla JavaScript

## Play locally

```bash
git clone https://github.com/WujecDamian/odin-RockPaperScissors.git
# Open index.html in browser
```
